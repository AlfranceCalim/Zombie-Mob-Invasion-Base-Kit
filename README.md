## 📖 About

**Zombie Mob Invasion Base Kit** is the stripped-down, barebones version of my game *Zombie Mob Invasion*. It ships with the core scripts and placeholder assets, so you get a clean, working starting point without any of the final art or content.

Use it to prototype fast, learn how a horde-survival game fits together, or mod it into something completely new.

> [!NOTE]
> All art, audio, and models in this kit are **placeholders**. Replace them with your own before releasing anything.

## ✨ Features

- 🧠 **Core gameplay scripts** ready to read, edit, and extend
- 🧱 **Placeholder assets** so the project runs out of the box
- 🧟 **Zombie mob foundation** for spawning and handling enemies
- 🔧 **Clean, modular structure** that is easy to fork and build on
- 🎮 **Prototype-friendly**: open the scene, press Play, start iterating

## 🚀 Getting Started

### Requirements

| Requirement | Version |
|---|---|
| Unity Editor | 2022.3 LTS or newer *(update to match your project)* |
| Git | Any recent version |

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/AlfranceCalim/zombie-mob-invasion-base-kit.git

# 2. Open the folder in Unity Hub
#    Unity Hub → Add → select the cloned folder

# 3. Open the main scene and press Play ▶️
```

> [!TIP]
> Use the **Fork** button first if you plan to build your own game on top of this kit.

## 🎨 Customizing the Kit

1. **Swap the art**: replace placeholder models, sprites, and materials
2. **Swap the audio**: drop in your own music and sound effects
3. **Extend the scripts**: add new enemy types, weapons, and waves
4. **Build your content**: new maps, UI, and progression
